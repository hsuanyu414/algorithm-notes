# Bit Manipulation

## 什麼時候用

- 需要進行位運算操作，如檢查某個位元是否為 1、設置某個位元為 1 或 0、翻轉某個位元等
- 要進行快速的乘除法運算，特別在整數時乘除以 2 的冪次
- 需要進行 XOR 運算來找出唯一的元素或進行加密解密

## 相關操作
- 檢查第 `k` 位是否為 1：
    - 方法
        - `(n >> k) & 1`，若結果為 1 則第 `k` 位為 1，為 0 則第 `k` 位為 0
    - 原理
        - 將 n 右移 k 位後，最低位即為原本的第 k 位，然後與 1 做 AND 運算即可檢查該位是否為 1
    - 例：
        - `n = 5 (0101)`，檢查第 2 位：
            - `(5 >> 2) & 1 = (0001) & 1 = 1`，第 2 位為 1
- 設置第 `k` 位為 1：
    - 方法
        - `n = n | (1 << k)`
    - 原理
        - 將 1 左移 `k` 位，得到一個只有第 `k` 位為 1 的數字，然後與 n 做 OR 運算即可將第 `k` 位設置為 1
    - 例：
        - `n = 5 (0101)`，設置第 1 位為 1：
            - `n = 5 | (1 << 1) = 5 | 2 = 7 (0111)`
- 設置第 `k` 位為 0：
    - 方法
        - `n = n & ~(1 << k)`
    - 原理
        - 將 1 左移 `k` 位，得到一個只有第 `k` 位為 1 的數字，然後取反得到一個只有第 `k` 位為 0 的數字，最後與 n 做 AND 運算即可將第 `k` 位設置為 0
    - 例：
        - `n = 5 (0101)`，設置第 2 位為 0：
            - `n = 5 & ~(1 << 2) = 5 & ~4 = 5 & 11 = 1 (0001)`  
- 翻轉第 `k` 位：
    - 方法
        - `n = n ^ (1 << k)`
    - 原理
        - 將 1 左移 `k` 位，得到一個只有第 `k` 位為 1 的數字，然後與 n 做 XOR 運算即可將第 `k` 位翻轉
    - 例：
        - `n = 5 (0101)`，翻轉第 0 位：
            - `n = 5 ^ (1 << 0) = 5 ^ 1 = 4 (0100)`
- 去除最低位的 1：
    - 方法
        - `n = n & (n - 1)`
    - 原理
        - `n-1` 會將 n 的最低位的 1 變為 0，其右邊的所有位元變為 1
        - 跟 `n` 做 AND 運算後，最低位的 1 會被去除
    - 例：`n = 12 (1100)`，`n-1 = 11 (1011)`，`n & (n - 1) = 8 (1000)`
- 判斷奇偶數：
    - 方法
        - `n & 1`，若結果為 1 則為奇數，為 0 則為偶數
    - 原理
        - 奇數的二進位表示中，最低位為 1；偶數的二進位表示中，最低位為 0
    - 例：
        - `n = 5 (0101)`，`n & 1 = 1`，為奇數
        - `n = 4 (0100)`，`n & 1 = 0`，為偶數
- 判斷是否為 2 的冪次：
    - 方法
        - `n > 0 && (n & (n - 1)) == 0`
    - 原理
        - 2 的冪次的二進位表示中，只有一個位元為 1，其餘位元為 0
        - `n > 0` 確保 n 為正數 (因為 2 的冪次必為正數)
        - `(n & (n - 1)) == 0` 去除最低位的 1 後，若結果為 0，表示 n 只有一個位元為 1 
- 計算二進位中 1 的個數
    - `__builtin_popcount(n)` (GCC/Clang 內建函數)
    - 使用 Brian Kernighan's Algorithm：
        ```cpp
        int count = 0;
        while (n) {
            n &= (n - 1);
            count++;
        }
        ```
        此方法每次迴圈都會去除 n 的最低位的 1，直到 n 為 0，計數器 count 就是二進位中 1 的個數。
    - 時間複雜度：$O(\text{1 的個數})$

## 特性
- `XOR` 
    - 特性：
        - `a ^ a = 0`
        - `a ^ 0 = a`
        - `a ^ b = b ^ a` (交換律)
        - `(a ^ b) ^ c = a ^ (b ^ c)` (結合律)
    - 用途：
        - 找出唯一的元素：
            - e.g. 若一個陣列中有一個恰好出現一次的元素，其餘元素都出現兩次，則可以使用 XOR 將所有元素 XOR 起來，最終結果就是唯一的元素。
            
## 注意事項

- 運算符優先順序問題：
    - `&, |, ^` 的優先順序低於 `==, !=, <, >`
    - `<<, >>` 的優先順序低於 `+, -`
